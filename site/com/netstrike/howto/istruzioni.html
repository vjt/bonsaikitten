Netstrike - Istruzioni per l'uso
Come posso partecipare?
[Le fasi sono in ordine crescente di complicazione, ma non vi spaventate: e' piu' facile a farsi che a dirsi ;-)]
L'unica cosa veramente necessaria per partecipare al netstrike sono le prime due sezioni di questa pagina che riguardano il divertimento di coordinarsi con gli altri mentre la protesta e' in atto e le informazioni minimali per fare la propria parte. Tutto il resto e surplus per chi proprio proprio vuole esagerare ;-)

Sezione Comunicazione e Coordinamento
  • Se avete un programma che di solito usate per chattare in IRC, settate come server www.ecn.org e come canale #hackit99, e venite a seguire in diretta l'evolversi del netstrike!
  • Se non avete un programma che di solito usate per chattare in IRC, collegatevi al servizio di chat di Isole nella Rete, controllando di avere abilitato java nelle impostazioni del vostro browser
  • Se non riuscite a intraprendere nessuno dei due punti precedenti, potrete seguire gli aggiornamenti in tempo reale sulla mailing list pubblicata Cyber Rights
Sezione Smart Browsing (o Navigazione Intelligente)
  • Aprite il vostro browser di fiducia [per questo non pensiamo siano necessarie altre specifiche;-]
  • Non impostate proxy per la vostra connessione
    NB E' possibile che voi non possiate navigare se non attraverso il proxy della vostra azienda o del vostro ufficio; in questo caso il nostro suggerimento e' quello di cercare un'altra postazione da cui partecipare al netstrike; in caso contrario la vostra patrtecipazione sara' limitata dalle impostazioni del vostro proxy (di solito abbastanza castranti :(
    • Internet Explorer
      1. Menu Visualizza
      2. Sezione Opzioni Internet
      3. Sottosezione Connessione
      4. Lasciate vuoto lo spazio in corrispondenza della voce Accedi a Internet tramite un Server Proxy
    • Netscape Navigator 3.x
      1. Menu Options
      2. Sezione Network Preferences
      3. Sottosezione Proxies
      4. Settate la voce No Proxies
    • Netscape Navigator 4.x e seguenti
      1. Menu Edit
      2. Sezione Preferences
      3. Sottosezione Advanced -> Proxies
      4. Settate questa voce su Connessione diretta ad Internet
    • Opera
      1. Menu File
      2. Sezione Preferences
      3. Sottosezione Connections
      4. Andate alla voce Proxy Servers e disabilitateli
  • Settate a 0 la cache del vostro browser
    • Internet Explorer - versione 1
      1. Menu Visualizza
      2. Sezione Opzioni Internet
      3. Sottosezione Generale
      4. File Temporanei Internet -> Impostazioni
      5. Settate Ricerca versioni piu' recenti delle pagine memorizzate:
        all'apertura della pagina
      6. Portate a 0 lo Spazio su disco da utilizzare per i File temporanei Internet
    • Internet Explorer - versione 2
      1. Scaricate disabilita.reg
      2. Lanciatelo con un doppio click
      3. Per ripristinare i settaggi originari scaricatevi riabilita.reg e fate la stessa cosa
    • Netscape Navigator 3.x
      1. Menu Options
      2. Sezione Network Preferences
      3. Sottosezione Cache
      4. Settate la voce Verify Documents su Every time
      5. Settate a 0 sia la Memory Cache che la Disk Cache e cliccate sui bottoni Clear Memory Cache e Clear Disk Cache
    • Netscape Navigator 4.x e seguenti
      1. Menu Edit
      2. Sezione Preferences
      3. Sottosezione Advanced -> Cache
      4. Settate Il confronto tra il documento memorizzato e la pagina corrente e' effettuato
        Ogni volta che si apre la pagina
      5. Settate a 0 sia la Memory Cache che la Disk Cache e cliccate sui bottoni Clear Memory Cache e Clear Disk Cache
    • Opera
      1. Menu File
      2. Sezione Preferences
      3. Sottosezione HIstory and Cache
      4. Voce Check Modified
      5. Settare tutte parti di questa voce su sempre
      6. Settate a 0 la voce Disk Cache
      7. Cliccate sul bottone Empty Now
  • Adesso digitate l'indirizzo interessato dal Netstrike nella vostra barra di navigazione
  • Continuate a schiacciare il tasto Aggiorna o Reload continuamente
    Se proprio volete essere sicuri di ricaricare la pagina ogni volta e di fare la vostra parte nel netstrike continuate a tenere premuto il tasto Shift mentre ricaricate la pagina con l'apposito bottone del vostro browser
  • Potete svolgere queste due ultime operazioni in diverse finestre contemporaneamente del vostro browser per aumentare la potenza di fuoco ;-))
    [Per aprire un'altra finestra Menu File -> Sezione Nuovo -> Sottosezione Finestra]
    Oppure, ancora meglio, svolgere le operazioni di questa sezione su piu' browser diversi (es: Explore e Navigator) contemporaneamente

Sezione Bandwidth (o Ampiezza dibbanda)
  • Siete in possesso di un software per scaricare interi siti?
    Se la risposta e' no potete scaricarvi Teleport Pro o wget che permettono di scaricarvi contemporaneamente piu' pagine del sito bersaglio, andando ad occupare praticamente tutta la banda di cui diponete e quindi massimizzando il vostro contributo al netstrike

      1. Menu File

      3. Poi seguite le istruzioni del wizard e riempite i campi con le informazioni che vi chiede:
        • Crea un duplicato del sito sul mio hard disk
        • Indirizzo interessato dal Netstrike come indirizzo di partenza
        • Scaricate sia testo che grafica
      4. Andate sull'indirizzo di partenza nella finestra sinistra del programma e cliccate con il pulsante destro del vostro mouse
      5. Sezione Proprieta' dell'indirizzo di partenza
      6. Settate Profondita' e Limiti dell'esplorazione su Fino a 10 link dall'indirizzo di partenza (scrivete dieci nel primo riquadro che trovate e segnate il primo pallino che si trova subito sotto, in pratica, nella finestra che si para davanti)

Sezione ProgPop (o Programmazione Popolare)
  • Loa Netstrike: simpatico scriptino in javascript inserito in una paginetta html frutto della malattia mentale hacara applicata alla grafica, prodotto qui al LOA per ricaricare ogni 20 secondi la pagina del Comune di Milano;
    requisito e' l'azzeramento della cache come descritto sopra
    Si consiglia di aprirlo sfasato di qualche secondo in piu' finestre in modo da massimizzare il numero di richieste effettuate sul server dell'indirizzo interessato dal Netstrike
  • disabilita.reg: file di registro per disabilitare la cache di explorer;
    salvatevi questo file sul vostro desktop e fate doppio click;
    per ripristinare i settaggi originali abbiamo prodotto anche riabilita.reg, che anch'esso va salvato sul vostro pc e lanciato con un doppio click
  • contributo di un amico hacaro alla causa: altro scriptino server side che reloada automaticamente le pagine del sito interessato dal Netstrike;
    requisito e' l'azzeramento della cache come sopra
    suggerita apertura contemporaneamente di piu' finestre con questa pagina
  • Jcounter by SpzkWebCrew:
    reload di una pagina ogni 10 sec
    Istruzioni per l'uso
    1. Impostare i parametri nel file counter.html (indirizzo e delay)
    2. Caricare la pagina jcounter.html
    3. il resto lo fa da lui...
    Suggerito azzeramento cache come al solito e piu' caricamenti della pagina jcounter.html
  • Arachne: scusate se lo abbiamo posizionato qui ma non rientrava in nessuna delle categorie precedenti
    1. digitare l'indirizzo del sito interessato dal Netstrike
    2. digitate il comando "q"
    3. attendere
    4. F8
    5. ripetere
